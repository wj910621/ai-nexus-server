# Y·NEX Desktop 项目路线图

> 最后更新：2026-10-28
> 本文档记录所有已规划但暂未实现的功能，防止遗忘。

---

## ✅ 已完成

### Phase 1：整合打通
- [x] 统一工具注册中心（UnifiedToolRegistry）- 49个内置技能
- [x] ReAct Agent 引擎 - 自动工具调用闭环
- [x] 技能中心面板 UI - 分类/搜索/卡片展示
- [x] 工具调用可视化 - 对话流实时展示

### Phase 2：MCP 生态
- [x] MCP 管理面板 - 添加/配置/管理服务器
- [x] 15个预设 MCP 服务器 - 一键快速添加
- [x] 技能市场雏形 - 本地导入导出 + 6个预置技能包

### Phase 3：Agent 工作流平台
- [x] 工作流引擎（WorkflowEngine）- 11种节点类型
- [x] 可视化工作流编辑器 - 拖拽式节点编辑
- [x] 多 Agent 协作系统 - 4个预设团队 + 6种角色
- [x] 触发器引擎（TriggerEngine）- 5种触发方式
- [x] Agent 市场 - 本地导入导出 + 6个预置Agent模板

### Phase 4：生态与商业化（核心已完成）
- [x] 技能市场 - 本地版（.yskill格式 + 导入导出 + 6个预置）
- [x] Agent 市场 - 本地版（.yagent格式 + 导入导出 + 6个预置）
- [x] 工作流模板市场 - 本地版（.yflow格式 + 导入导出 + 6个预置）
- [x] 统一市场中心 UI - 三大市场Tab切换
- [x] 积分定价系统 - Python + Node.js双版本
- [x] 会员体系 - 免费/月度/年度/终身版四级权益
- [x] 终身版限量涨价机制 - 500名额，每100个涨10%
- [x] 会员中心 UI - 积分概览/套餐选择/充值/统计/交易记录
- [x] 顶部积分显示栏 - 实时展示积分和会员状态
- [x] 积分充值包体系 - 5档阶梯定价，多买多送
