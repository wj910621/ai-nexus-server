🎨

拖拽式节点编辑，类似 n8n / Dify。支持条件分支、循环、并行、子流程，所见即所得。

多 Agent 协作

🏪

Agent 市场

用户可以分享和下载自定义 Agent、工作流模板、技能包，形成生态闭环。

⏰

定时/触发器系统

Webhook 触发、定时触发、事件触发、文件监听触发，让工作流全自动运行。
